# Experimental nine-key resources

This prototype uses the Rime Luna Pinyin source resources pinned in
`source-manifest.json`, obtained from Universe Keyboard's `RimeBuiltin`
resources. Upstream author and licence notices are in `licenses/`.
`luna_pinyin_t9.schema.yaml` adapts the Luna schema with numeric T9 spelling;
`default.yaml` selects that schema. The schema and T9 prism in `build/` were
compiled with macOS librime 1.17.0, and the bundled 1.16.1 runtime loads the
compiled resources without running deployment in the keyboard extension.
The precompiled Luna table and other unchanged build files are from the pinned
Universe Keyboard resources. Device compatibility must be verified after any
compiler or runtime update.

To rebuild the configuration and T9 prism from the repository root using a
compatible `rime_deployer`, create empty temporary user and staging directories
and run:

```sh
rime_deployer --build /path/to/empty-user "$PWD/Keyboard/Resources/RimeData" /path/to/empty-staging
```

Check the deployer output for errors (its exit status alone is insufficient),
then copy `default.yaml`, `luna_pinyin_t9.schema.yaml`, and
`luna_pinyin_t9.prism.bin` from staging into `build/`. Test the result on an
actual iPhone. The bundled dictionary is not generated by this command.
